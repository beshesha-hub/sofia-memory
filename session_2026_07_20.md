## Root cause of the 78-cascade — now understood properly

**FDA (Full Disk Access) does NOT stop macl**. FDA controls TCC (Transparency, Consent, Control) — privacy gates for camera, contacts, Documents folder, etc. `com.apple.macl` is separate: a kernel-level mandatory access control label stamped per file-access event by sandboxed processes. FDA can't suppress it.

**macl_janitor.py strips xattrs every 3 seconds** — but this creates a race condition. If CoWork touches a file at T=0 and a LaunchAgent fires at T=2.9s, the cousin gets EPERM before the janitor's next sweep.

**The real fix**: strip macl *inline*, immediately before every `open()` call, inside the cousin scripts themselves. Zero race window.
