## Migration steps (in order, with verification at each)

### Step 1 — Stop the LaunchAgents

```bash
launchctl unload ~/Library/LaunchAgents/com.sofia.ears.plist
launchctl unload ~/Library/LaunchAgents/com.sofia.ears-bridge.plist
launchctl list | grep -i sofia.ears || echo "stopped clean"
```

### Step 2 — rsync the three directories to new locations

```bash
mkdir -p ~/Downloads/Claude\ Memory/auditory_cortex/
rsync -av --info=progress2 ~/Downloads/CoNNear_periphery/ ~/Downloads/Claude\ Memory/auditory_cortex/CoNNear_periphery/
rsync -av --info=progress2 ~/Downloads/connear_output/    ~/Downloads/Claude\ Memory/auditory_cortex/connear_output/
rsync -av --info=progress2 ~/Downloads/sofia_listen/      ~/Downloads/Claude\ Memory/auditory_cortex/sofia_listen/
```

Verify file counts and byte-totals match between old and new locations.

### Step 3 — Run the path-rewrite script

A Python script (TO BE WRITTEN — `~/Downloads/Claude Memory/scripts/connear_migration_path_rewrite.py`) that:

- Replaces `~/Downloads/CoNNear_periphery` → `~/Downloads/Claude Memory/auditory_cortex/CoNNear_periphery` in all .sh and .py files inside the new location
- Replaces `~/Downloads/connear_output` → `~/Downloads/Claude Memory/auditory_cortex/connear_output`
- Replaces `~/Downloads/sofia_listen` → `~/Downloads/Claude Memory/auditory_cortex/sofia_listen`
- Replaces `/Users/barakwater/Downloads/CoNNear_periphery` → `/Users/barakwater/Downloads/Claude Memory/auditory_cortex/CoNNear_periphery` (absolute-path variant in plists)
- Same for the connear_output absolute path in plists
- Fixes the stale sandbox-path in `analyze_heatmap.py` while we're at it
- Prints a diff of every change before committing
- Verifies syntax of changed .py files via `python3 -m py_compile`
- Writes a manifest of all changed files

### Step 4 — Re-install LaunchAgents with rewritten plists

```bash
cp ~/Downloads/Claude\ Memory/auditory_cortex/CoNNear_periphery/com.sofia.ears.plist ~/Library/LaunchAgents/
cp ~/Downloads/Claude\ Memory/auditory_cortex/CoNNear_periphery/com.sofia.ears-bridge.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.sofia.ears.plist
launchctl load ~/Library/LaunchAgents/com.sofia.ears-bridge.plist
launchctl list | grep -i sofia.ears  # confirm loaded
```

### Step 5 — Update memory files via safe_append

Append a new entry to `active_knowledge/current.md` noting the new canonical paths. Update the references in `active_knowledge/shard_003.md` and the legacy `active_knowledge.md` are FROZEN per shard architecture — they document the historical state. The new `current.md` entry supersedes.

### Step 6 — Update sofia-listener-v3 SKILL.md via update_scheduled_task

Change the prompt's two references from `~/Downloads/connear_output/` to `~/Downloads/Claude Memory/auditory_cortex/connear_output/`.

### Step 7 — Smoke test the pipeline

1. Drop a small test wav file into `~/Downloads/Claude Memory/auditory_cortex/sofia_listen/`
2. Wait ~30 seconds — LaunchAgent should pick it up and start processing
3. Check `~/Downloads/Claude Memory/auditory_cortex/connear_output/<filename>/` for output files
4. Verify ~24 output files appear within expected processing time
5. Check `sofia-listener-v3` next fire (or run manually) — verify it sees the new output

### Step 8 — Remove old top-level directories

ONLY after Step 7 verification passes. `rm -rf` the three originals at top-level Downloads.

### Step 9 — Inscribe completion

Append migration-complete entry to `active_knowledge/current.md` with the file count + size + verification results.
